Wie soll die Visualisierung funktionieren?

Drei unterschiedliche Ansätze — von einfach bis vollständig neu gebaut

A

Icons + Text bleibt

Jede Kategorie bekommt ein Repräsentations-Item links vom Namen. Pattern-Eingabe bleibt als Text, aber eine Live-Vorschau zeigt dir, welche echten Items das Pattern trifft.

Vorteile

  • Wenig Aufwand
  • YACL bleibt erhalten
  • Pattern-Kontrolle bleibt präzise

Nachteile

  • Immer noch Text-Eingabe nötig
  • Keine echten Texturen
B

Eigener Category-Editor-Screen

Ein komplett eigener Minecraft-Screen (kein YACL). Kategorien als Tabs oben, darunter ein Item-Grid — Klick auf ein Item fügt es zur Kategorie hinzu oder entfernt es. Mit Suchleiste.

  • Neuer Screen außerhalb von YACL
C

Item-Picker als Popup

Im YACL-Screen bei "Patterns" gibt es einen "+ Item wählen"-Button. Klick öffnet ein Popup mit scrollbarem Item-Grid und Suche. Gewähltes Item wird als Pattern eingetragen. Pattern-Text bleibt als Alternative.
