3 — Technische Eckpunkte

  • Neuer Screen: CategoryEditorScreen extends Screen — eigenständig, kein YACL
  • Item-Liste: BuiltInRegistries.ITEM → alle ~1200 Vanilla-Items, live gerendert mit echter Textur
  • Pattern-Matching: bestehende ItemCategorizer-Logik wiederverwendet um anzuzeigen was matcht
  • Item hinzufügen: Klick → fügt exakte Item-ID als Pattern ein (z.B. minecraft:repeater)
  • Item entfernen: Klick auf grünes Item links → entfernt das exakte-ID-Pattern (Wildcards bleiben)
  • Wildcard-Chips: Klick auf ✕ entfernt das Pattern — Items die nur durch diesen Wildcard drin waren, verschwinden aus der Anzeige
  • Config bleibt kompatibel: patterns-Liste in TOML-Format unverändert
  • Kein ScrollWidget-Framework: eigene Scroll-Logik per Mouse-Drag / Scrollrad
